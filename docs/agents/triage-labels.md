# Triage Labels

The engineering skills use five triage roles. For local Markdown issues, record the matching name in a `Status:` line.

| Role              | Status value      | Meaning                                |
| ----------------- | ----------------- | -------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue |
| `needs-info`      | `needs-info`      | Waiting for more information           |
| `ready-for-agent` | `ready-for-agent` | Specified and ready for an agent       |
| `ready-for-human` | `ready-for-human` | Requires human implementation          |
| `wontfix`         | `wontfix`         | Will not be actioned                   |

When a skill mentions a role, use its status value from this table.
