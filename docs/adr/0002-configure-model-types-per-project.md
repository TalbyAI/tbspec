# Configure model types per project

Each project starts with ready-to-use `data`, `process`, and `state-machine` model types backed by versioned RDF ontologies and may define additional types. A project may replace, disable, or reset a type's ontology association. Disabling prevents new models of that type while existing models remain valid and editable. Replacing an ontology disconnects its previous visual design; the project explicitly selects a design, even if it reuses the supplied one for a local copy. Until then, generic graph editing remains available. Specialized forms recognize known terms independently of the selected visual design. The tool does not translate replacement concepts into the supplied ontology's concepts. This permits incompatible third-party and locally edited vocabularies while retaining ready-to-use defaults.
