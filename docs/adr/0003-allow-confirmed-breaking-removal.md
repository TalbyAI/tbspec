# Allow confirmed removal that breaks references

Before deleting a model type or resource, the tool shows incoming references and affected files. The user can then confirm the deletion even if those references remain. Validation and project status report the resulting invalid state until the references are repaired. The CLI supports previewed redirection or removal of dangling references; invalid RDF syntax must first be corrected in the source file. Orphaned project-owned support resources remain until a separate, confirmed garbage collection removes them. Independent designs and locked dependencies require their own removal commands. This keeps deliberate restructuring possible without a silent cascade. Projects using Git rely on it for history; the tool does not implement a second revision system.
