# Select the RDF engine and runtime baseline

Type: grilling
Status: ready-for-human
State: open
Blocked by: 04

## Question

Given the integrated proof, which RDF engine and runtime form should the MVP adopt? Apply the agreed priority order: contract fidelity and local-query security first, accessible English documentation for core dependencies, then implementation simplicity and a single installed runtime. Prefer Node when Node/RDF.js and embedded Jena are equally sound. Record why dotNetRDF, RDFLib/pySHACL, and RDF4J were not in the first proof, and use an ADR if the choice meets the repo's ADR threshold.
